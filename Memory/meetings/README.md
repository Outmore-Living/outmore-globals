# Meeting Notes

Notes, decisions, and action items from meetings, calls, and conversations.

## File Naming

```
YYYY-MM-DD-topic.md
```

Example: `2025-02-13-supplier-review.md`, `2025-03-01-marketing-sprint.md`

## Template

```markdown
# [Meeting Topic] — YYYY-MM-DD

## Attendees
-

## Agenda
-

## Key Decisions
-

## Action Items
- [ ] [Owner] — [Task] — [Due date]

## Notes
-
```

## Retention

- Keep indefinitely for decision audit trail
- Move meeting series to `archive/` when the project ends
