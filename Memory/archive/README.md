# Archive

Completed, retired, or historical memory files. Moved here to keep active directories clean while preserving institutional knowledge.

## What Goes Here

- Daily logs older than 30 days
- Completed project memory files
- Meeting notes from finished projects
- Outdated references (kept for historical context)

## File Naming

Keep original filename, prefix with source directory:

```
daily-2025-01-15.md
project-old-website.md
meeting-2025-01-20-kickoff.md
```

## Retention

- Review annually — delete anything that's truly irrelevant
- If an archived file becomes relevant again, move it back to its original directory
