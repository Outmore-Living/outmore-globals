# Daily Memory

Short-lived notes from daily work sessions. What happened today, what's in progress, what's blocked.

## File Naming

```
YYYY-MM-DD.md
```

Example: `2025-02-13.md`

## Template

```markdown
# YYYY-MM-DD

## Done
-

## In Progress
-

## Blocked
-

## Notes
-
```

## Retention

- Keep for 30 days
- Move anything worth keeping long-term to `LTmemory.md` or `projects/`
- Archive old dailies to `archive/` monthly
