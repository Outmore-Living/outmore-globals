# References

Bookmarked resources, articles, examples, and inspiration. Things we've found useful and want to find again.

## File Naming

Organize by topic:

```
topic-name.md
```

Example: `nextjs-patterns.md`, `seo-resources.md`, `design-inspiration.md`

## Template

```markdown
# [Topic] References

## Articles
- [Title](URL) — Brief note on why it's useful

## Code Examples
- [Repo/File](URL) — What pattern it demonstrates

## Tools
- [Tool](URL) — What it does, when to use it

## Inspiration
- [Site/Design](URL) — What to take from it
```

## Retention

- Review quarterly — remove dead links and outdated resources
- Star or bold the most important references
