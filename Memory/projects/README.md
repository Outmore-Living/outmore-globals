# Project Memory

Per-project context, decisions, and state. One file per active project.

## File Naming

```
project-name.md
```

Example: `outmore-website.md`, `heated-bench-landing.md`

## Template

```markdown
# Project: [Name]

## Overview
Brief description of what this project is.

## Status
Active / Paused / Complete

## Key Decisions
| Decision | Choice | Why | Date |
|----------|--------|-----|------|

## Architecture Notes
-

## Open Questions
-

## Links
- Repo:
- Vercel:
- Supabase project:
```

## Retention

- Keep active project files indefinitely
- Move completed projects to `archive/` with a completion date
