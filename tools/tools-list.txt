--- ACTIVATION CHECKLIST ---

To fully activate all MCP servers, complete these steps:

[ ] Linear:       Paste API key into ~/.claude.json (get from linear.app > Settings > API)
[ ] Google:       Run Google Workspace MCP — it will open OAuth flow in browser
[ ] WhatsApp:     Run whatsapp-bridge first: cd ~/.mcp-servers/whatsapp-mcp/whatsapp-bridge && ./whatsapp-bridge
                  Then scan QR code with WhatsApp mobile app
[ ] iMessage:     Grant Full Disk Access: System Settings > Privacy > Full Disk Access > add Terminal/Claude
[ ] WeChat:       Install modified WeChat per wechat-exporter instructions, then login
[ ] Canva:        Set up at canva.dev, get API credentials, configure MCP manually
[ ] Fusion 360:   Install AuraFriday MCP add-in from Autodesk App Store
